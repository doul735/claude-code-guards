# GOTCHAS — ask-top-models

> 실제로 실패한 지점만 적는다.

- 두 모델 모두 "브리프만 읽고 아무것도 실행하지 않았다"고 했다. 실제로 값을 낸 것은 한 모델이 숫자 합계를 다시 계산해 브리프의 오류를 찾은 일 하나였다. 그래서 요구 항목 E(직접 확인 1개 이상)를 넣었다. 모델의 반박은 의견만으로는 값이 작고, 확인이 섞일 때 값이 난다.
- OpenAI 쪽 실행이 `timeout 580 codex …`에서 종료 코드 127로 실패했다. macOS에는 기본으로 `timeout` 명령이 없다. 그래서 `command -v timeout`으로 있을 때만 붙인다. 이때 `T='timeout 580'; $T codex …`처럼 변수에 담아 쓰면 안 된다 — zsh는 따옴표 없는 변수를 낱말로 가르지 않아 `timeout 580` 한 덩어리를 명령 이름으로 찾다 실패한다. 그래서 `if … then (timeout 있는 줄) else (없는 줄) fi` 두 갈래로 적었다.
- 모델 목록의 `priority` 값을 서열로 읽어 최상위가 아닌 모델을 골랐다. `priority`는 화면에 보이는 순서일 뿐이다. 그래서 정본을 사람이 적은 대응표로 두고, 목록은 "그 모델이 실제로 있는지" 확인하는 데만 쓴다.
- 두 모델이 "모른다"고 한 항목을 직접 재 보니, 제안의 규칙 하나가 통째로 틀린 것으로 드러났다. D(모르는 것)는 보고서에 옮겨 적는 칸이 아니라 **메인이 직접 재는 목록**이다.
